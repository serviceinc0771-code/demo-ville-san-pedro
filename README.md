# San-Pédro — démo marketing / culture

Site statique **Astro + Tailwind** pour San-Pédro (Côte d’Ivoire) : port, lagune, plages (Monogaga), culture locale.

## Pages

- `/` — Accueil (hero immersif)
- `/decouvrir` — Culture, lieux, plages
- `/pratiques` — Infos voyageur / local
- `/contact` — Formulaire démo (pas d’envoi serveur)

## Stack

- Astro 7, Tailwind CSS 4
- Polices : Fraunces (titres) + DM Sans (corps)
- Contenu FR, mobile-first, `prefers-reduced-motion` respecté

## Commandes

```bash
npm install
npm run dev
npm run build
npm run preview
```

Build de sortie : `dist/`.

## Note

Contenu fictionnel crédible, balisé **Démo** où besoin. Pas d’avis ni certifications inventés. Pas de déploiement inclus.
